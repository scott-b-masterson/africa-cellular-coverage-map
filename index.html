GSMA Reported Cellular Data Coverage in Africa

A harmonized map of reported 2G, 3G, and 4G mobile network coverage across the 2012 through 2018 GSMA Mobile Coverage Explorer releases.

Map

This figure shows the geographic extent of operator-reported 2G, 3G, and 4G coverage included in annual GSMA releases. Areas classified as having either strong or variable signal were combined into a single mapped coverage category and aligned to a common 1 km grid.

The figure displays 2012 through 2018 because this is the common period for all three technologies. Available 2G and 3G releases from 2007 through 2011 were omitted from the figure for formatting purposes.

Description and interpretation

Each panel represents the coverage reported in a particular annual GSMA release. It does not represent only the coverage added during that year. The named release year generally reflects operator information received through approximately the end of the preceding calendar year. For example, the 2016 release includes operator information received through approximately the end of 2015.

The source rasters classify covered areas using two signal categories:

Value 1
Strong signal strength
Value 2
Variable signal strength

Both source categories were combined for this map. Each colored area therefore represents mapped coverage, whether the source classified the signal as strong or variable. The final figure does not distinguish between the two classes.

The map is intended to show the spatial and temporal coverage of the available source data. It does not measure subscriber adoption, individual mobile phone use, network speed, or signal quality experienced by users. It is also not based on independent field measurements of cellular signal at every location.

Data limitations

The cellular coverage data were sourced from network operator submissions. The source metadata state that not every operator submitted information, which creates inevitable gaps in the coverage records.

Differences between annual releases may therefore reflect changes in operator participation, reporting, source submissions, or product construction, as well as actual changes in cellular networks. An area without mapped coverage does not necessarily indicate that cellular service was unavailable.

One notable example is the broad reported 4G footprint in the 2016 release, followed by substantially less mapped coverage in the 2017 release. This pattern is also visible in the original online source maps. It was retained as a feature of the published data rather than adjusted to impose increasing coverage over time.

Spatial processing

The original releases included a mixture of vector and raster formats. The data were processed in ArcGIS Pro to create a consistent annual series for Africa. The main processing steps included:

  • Selecting one source dataset for each available technology and release year
  • Confirming and correcting coordinate system metadata where necessary
  • Projecting the data to Africa Albers Equal Area Conic
  • Aligning all outputs to a common 1 km equal-area grid
  • Using nearest-neighbor resampling for categorical values
  • Combining strong and variable signal classes into a single mapped coverage category
  • Applying a consistent African land boundary and raster mask

The harmonized output uses the following convention:

1
Strong or variable coverage mapped in the annual release
0
No coverage mapped in the annual release within the African study area
NoData
Location outside the African study area

A value of zero should be interpreted as no coverage mapped in the release, not as confirmed evidence that cellular service was unavailable.

Data sources and credit

Cellular coverage data

The underlying mobile coverage data were obtained through Stanford EarthWorks, Stanford University Libraries' geospatial data discovery platform.

The GSMA Mobile Coverage Explorer records can be found through the following catalog search:

Browse GSMA Mobile Coverage Explorer records in Stanford EarthWorks

According to the source metadata, the coverage information was sourced from network operators through GSMA and Collins Bartholomew. Users should consult each EarthWorks record for release-specific metadata, rights statements, access conditions, and preferred citations.

Country boundaries

The African study boundary was derived from the Esri World Countries dataset.

Processing and cartography

Data processing and cartography were completed by Scott Masterson using ArcGIS Pro.
